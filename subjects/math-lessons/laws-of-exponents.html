What are Exponents?

An exponent tells us how many times a number or variable is used as a factor in multiplication.

For example:

24

means:

2 × 2 × 2 × 2

Therefore:

24 = 16

Base and Exponent

In 53, the number 5 is the base and 3 is the exponent.

The expression means:

5 × 5 × 5 = 125

Exponents provide a shorter way to write repeated multiplication.

Parts of an Exponential Expression

An exponential expression usually has a base and an exponent.

Consider:

x5

x is the base.

5 is the exponent.

This means:

x × x × x × x × x

Example with a Number

34

Base = 3

Exponent = 4

3 × 3 × 3 × 3 = 81

Product Rule

When multiplying powers with the same base, keep the base and add the exponents.

The rule is:

am × an = am+n

Example

x3 × x4

Add the exponents:

3 + 4 = 7

Therefore:

x3 × x4 = x7

Numerical Example

23 × 22

= 23+2

= 25

= 32

This rule only applies when the bases are the same.

Quotient Rule

When dividing powers with the same base, keep the base and subtract the exponent in the denominator from the exponent in the numerator.

The rule is:

am ÷ an = am−n

Example

x7 ÷ x3

Subtract the exponents:

7 − 3 = 4

Therefore:

x7 ÷ x3 = x4

Numerical Example

56 ÷ 52

= 56−2

= 54

= 625

Power of a Power Rule

When a power is raised to another power, multiply the exponents.

The rule is:

(am)n = amn

Example

(x3)4

Multiply the exponents:

3 × 4 = 12

Therefore:

(x3)4 = x12

Numerical Example

(22)3

= 22×3

= 26

= 64

Power of a Product Rule

When a product is raised to a power, apply the exponent to every factor inside the parentheses.

The rule is:

(ab)n = anbn

Example

(xy)3

Apply the exponent to both variables:

x3y3

Therefore:

(xy)3 = x3y3

Numerical Example

(2 × 3)2

= 22 × 32

= 4 × 9

= 36

Power of a Quotient Rule

When a quotient is raised to a power, apply the exponent to both the numerator and denominator.

The rule is:

(a/b)n = an/bn

Example

(x/y)3

Apply the exponent to both parts:

x3/y3

Therefore:

(x/y)3 = x3/y3

Numerical Example

(2/3)2

= 22/32

= 4/9

Zero Exponent Rule

Any nonzero number raised to the zero power equals 1.

The rule is:

a0 = 1

where a is not zero.

Examples

50 = 1

1000 = 1

x0 = 1

This rule is useful when simplifying expressions involving division or other exponent laws.

Example

x5 ÷ x5

= x5−5

= x0

= 1

Negative Exponent Rule

A negative exponent indicates the reciprocal of the expression with the corresponding positive exponent.

The rule is:

a−n = 1/an

Example

x−3

Move x3 to the denominator:

1/x3

Therefore:

x−3 = 1/x3

Numerical Example

2−4

= 1/24

= 1/16

Therefore:

2−4 = 1/16

Fractional Exponents

A fractional exponent can represent a root.

The basic rule is:

a1/n = n√a

A denominator in the exponent indicates the root.

Example

91/2

= √9

= 3

Another Example

81/3

= ∛8

= 2

General Form

More generally:

am/n = n√(am)

Fractional exponents are another way of representing roots and powers.

Simplifying Exponential Expressions

The laws of exponents can be used together to simplify complicated expressions.

Example 1

Simplify:

x3 × x5

Use the Product Rule:

x3+5

= x8

Example 2

Simplify:

x9 ÷ x4

Use the Quotient Rule:

x9−4

= x5

Example 3

Simplify:

(x2)3

Use the Power of a Power Rule:

x2×3

= x6

Example 4

Simplify:

x5 × x−2

Add the exponents:

5 + (−2) = 3

Therefore:

x3

Evaluating Expressions with Exponents

To evaluate an expression containing exponents, substitute the given value and follow the correct order of operations.

Example

Evaluate:

x2 + 3x

when x = 4.

Substitute 4:

42 + 3(4)

Evaluate the exponent first:

16 + 12

= 28

Example with Parentheses

Evaluate:

(x + 2)2

when x = 3.

Substitute:

(3 + 2)2

= 52

= 25

Common Mistakes

Understanding what each law does is important because different operations use different exponent rules.

1. Adding Exponents When Dividing

This is incorrect:

x6 ÷ x2 = x8

For division, subtract the exponents:

x6 ÷ x2 = x4

2. Multiplying Exponents in the Product Rule

This is incorrect:

x3 × x4 = x12

When multiplying powers with the same base, add the exponents:

x3 × x4 = x7

3. Forgetting to Apply an Exponent to Every Factor

For example:

(xy)2

The correct result is:

x2y2

4. Confusing a Negative Exponent with a Negative Number

A negative exponent does not automatically make the value negative.

For example:

2−2 = 1/4

The result is positive.

Summary

Exponents provide a short way to represent repeated multiplication. The laws of exponents make it easier to simplify exponential expressions.

Important Laws of Exponents

Product Rule:

am × an = am+n

Quotient Rule:

am ÷ an = am−n

Power of a Power:

(am)n = amn

Power of a Product:

(ab)n = anbn

Power of a Quotient:

(a/b)n = an/bn

Zero Exponent:

a0 = 1

Negative Exponent:

a−n = 1/an

Fractional Exponent:

a1/n = n√a

Quick Examples

x3 × x2 = x5

x8 ÷ x3 = x5

(x2)4 = x8

x0 = 1

x−3 = 1/x3

The most important step is to identify the operation being performed before choosing which exponent law to use.
