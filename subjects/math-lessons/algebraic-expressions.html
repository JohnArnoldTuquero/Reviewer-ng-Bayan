What is an Algebraic Expression?

An algebraic expression is a mathematical phrase that contains numbers, variables, and mathematical operations. Unlike an equation, an algebraic expression does not contain an equal sign.

Examples of algebraic expressions include:

3x + 5

7a − 2

4x2 + 3x + 1

12 − 5y

Algebraic expressions are used to represent quantities and relationships using symbols and numbers.

Expression vs. Equation

An expression does not have an equal sign:

3x + 7

An equation contains an equal sign:

3x + 7 = 16

Parts of an Algebraic Expression

An algebraic expression can contain several important parts, including variables, constants, coefficients, and terms.

Example

Consider the expression:

5x + 8

The number 5 is the coefficient.

The letter x is the variable.

The number 8 is the constant.

The terms are 5x and 8.

Understanding these parts makes it easier to simplify and evaluate algebraic expressions.

Variables

A variable is a letter or symbol used to represent an unknown or changing value.

Common variables include:

x, y, z, a, b, and n

Example

In the expression:

4x + 3

x is the variable.

If x = 5, the expression can be evaluated:

4(5) + 3 = 20 + 3 = 23

The value of a variable can change depending on the situation.

Constants

A constant is a number whose value does not change within an algebraic expression.

Example

In:

7x + 12

12 is the constant.

In:

3a − 9

−9 is the constant.

A constant does not have a variable attached to it.

Coefficients

A coefficient is the numerical factor that is multiplied by a variable.

Examples

In 5x, the coefficient is 5.

In −8y, the coefficient is −8.

In 12a2, the coefficient is 12.

When a variable has no visible coefficient, the coefficient is understood to be 1.

Therefore:

x = 1x

and:

−y = −1y

Terms

A term is a number, variable, or product of numbers and variables separated by addition or subtraction signs.

Example

Consider:

4x + 7y − 3

This expression has three terms:

4x

7y

−3

Another Example

The expression:

6a2 − 4a + 9

has three terms:

6a2, −4a, and 9.

Like and Unlike Terms

Like terms are terms that have the same variables raised to the same powers. Their coefficients may be different.

Like Terms

Examples:

3x and 7x

5a2 and −2a2

4xy and 9xy

These terms can be combined because their variable parts are the same.

Unlike Terms

Unlike terms have different variables or different powers.

Examples:

3x and 3y

4x and 4x2

2a and 5b

Unlike terms cannot be combined by simply adding or subtracting their coefficients.

Classifying Algebraic Expressions

Algebraic expressions can be classified according to the number of terms they contain.

Monomial

A monomial has exactly one term.

Examples:

5x

8

3a2

Binomial

A binomial has exactly two terms.

Examples:

x + 4

3a − 7

Trinomial

A trinomial has exactly three terms.

Examples:

x2 + 5x + 6

2a2 − 3a + 1

Polynomial

A polynomial is an expression made up of one or more terms in which the variables have non-negative integer exponents.

Monomials, binomials, and trinomials are all types of polynomials.

Evaluating Algebraic Expressions

Evaluating an algebraic expression means finding its numerical value when values are given for the variables.

Steps

1. Substitute the given value for the variable.

2. Use parentheses when necessary.

3. Follow the order of operations.

Example 1

Evaluate:

3x + 5, when x = 4.

Substitute 4 for x:

3(4) + 5

12 + 5 = 17

Example 2

Evaluate:

2x2 + 3, when x = 5.

Substitute:

2(5)2 + 3

2(25) + 3

50 + 3 = 53

Simplifying Algebraic Expressions

Simplifying an algebraic expression means rewriting it in a simpler equivalent form.

One of the most common methods is combining like terms.

Example

Simplify:

4x + 7 + 3x

Identify the like terms:

4x and 3x are like terms.

Add their coefficients:

4x + 3x = 7x

Therefore:

4x + 7 + 3x = 7x + 7

Combining Like Terms

Like terms can be combined by adding or subtracting their coefficients while keeping the variable part unchanged.

Example 1

Simplify:

5x + 3x

Add the coefficients:

5 + 3 = 8

Therefore:

5x + 3x = 8x

Example 2

Simplify:

9y − 4y + 2

Combine the like terms:

9y − 4y = 5y

Therefore:

9y − 4y + 2 = 5y + 2

Important

Only like terms can be combined.

For example:

3x + 4y

cannot be simplified by combining 3x and 4y because they are unlike terms.

Distributive Property

The distributive property is used to multiply a number or term by every term inside parentheses.

The general form is:

a(b + c) = ab + ac

Example 1

Simplify:

3(x + 4)

Multiply 3 by each term:

3(x) + 3(4)

3x + 12

Example 2

Simplify:

5(2x − 3)

Distribute 5:

5(2x) − 5(3)

10x − 15

Negative Numbers

Be careful with signs when distributing a negative number.

Example:

−2(x + 5)

Distribute −2:

−2x − 10

Therefore:

−2(x + 5) = −2x − 10

Translating Words into Algebraic Expressions

Algebra can be used to represent mathematical statements written in words.

Common Mathematical Words

Sum means addition.

Difference means subtraction.

Product means multiplication.

Quotient means division.

More than usually indicates addition.

Less than usually indicates subtraction, with attention to the order of the numbers.

Examples

"Five more than a number x":

x + 5

"Seven less than a number y":

y − 7

"Three times a number n":

3n

"A number x divided by 4":

x ÷ 4

or:

x/4

Algebraic Expressions in Word Problems

Algebraic expressions are useful for representing quantities in real-life situations.

Example 1

A notebook costs ₱50. If you buy x notebooks, what expression represents the total cost?

Each notebook costs ₱50.

Number of notebooks = x.

Therefore:

50x

The total cost is represented by 50x.

Example 2

Maria has x pesos and receives ₱100 more. What expression represents the amount of money she has now?

Starting amount = x

Additional amount = 100

Therefore:

x + 100

Example 3

A rectangle has a length of x meters and a width of 5 meters. Its perimeter can be represented by:

P = 2x + 10

This is an algebraic expression that represents the perimeter in terms of x.

Summary

An algebraic expression is a mathematical phrase containing numbers, variables, and operations.

Important Terms

Variable: A letter or symbol representing an unknown or changing value.

Constant: A number whose value does not change.

Coefficient: The numerical factor multiplied by a variable.

Term: A number, variable, or product separated by addition or subtraction.

Like terms: Terms with the same variable parts and the same exponents.

Monomial: An expression with one term.

Binomial: An expression with two terms.

Trinomial: An expression with three terms.

Key Skills

To evaluate an expression, substitute the given values and follow the order of operations.

To simplify an expression, combine like terms.

To expand parentheses, use the distributive property.

Algebraic expressions can also be created from words and used to represent real-life quantities.

Quick Examples

3x + 5 → an algebraic expression

4x + 2x = 6x → combining like terms

3(x + 4) = 3x + 12 → distributive property

If x = 5:

2x + 3 = 2(5) + 3 = 13
