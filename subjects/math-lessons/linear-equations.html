What is a Linear Equation?

A linear equation is an equation in which the variable has a highest exponent of 1.

Examples of linear equations include:

x + 5 = 12

3x - 7 = 11

2x + 4 = x + 9

The goal when solving a linear equation is usually to find the value of the variable that makes the equation true.

For example:

x + 5 = 12

The value of x that makes the equation true is 7, because:

7 + 5 = 12

Therefore, x = 7 is the solution.

Parts of a Linear Equation

Consider the equation:

4x + 7 = 19

The expression on the left side of the equal sign is the left-hand side.

The expression on the right side is the right-hand side.

The equal sign = indicates that both sides have the same value.

Variable

The variable is the unknown quantity. In the equation above, x is the variable.

Coefficient

The coefficient is the number multiplying the variable. In 4x, the coefficient is 4.

Constant

A constant is a number without a variable. In 4x + 7 = 19, both 7 and 19 are constants.

Solution of a Linear Equation

A solution is a value that makes an equation true.

Consider:

2x + 3 = 11

Try x = 4:

2(4) + 3 = 11

8 + 3 = 11

11 = 11

The equation is true, so:

x = 4

is the solution.

The main objective when solving an equation is to isolate the variable on one side of the equation.

Properties of Equality

When solving equations, we must maintain equality. Whatever operation is performed on one side should also be performed on the other side.

Addition Property of Equality

If a = b, then:

a + c = b + c

Example:

x - 5 = 10

Add 5 to both sides:

x - 5 + 5 = 10 + 5

x = 15

Subtraction Property of Equality

If a = b, then:

a - c = b - c

Multiplication Property of Equality

If a = b, then:

ac = bc

Division Property of Equality

If a = b and c ≠ 0, then:

a/c = b/c

These properties allow us to perform the same operation on both sides while keeping the equation balanced.

One-Step Linear Equations

A one-step equation can be solved using a single operation.

Addition

Example:

x + 8 = 15

Subtract 8 from both sides:

x = 7

Subtraction

Example:

x - 6 = 10

Add 6 to both sides:

x = 16

Multiplication

Example:

5x = 35

Divide both sides by 5:

x = 7

Division

Example:

x/4 = 6

Multiply both sides by 4:

x = 24

Two-Step Linear Equations

A two-step equation requires two operations to isolate the variable.

Consider:

3x + 5 = 20

First, remove the constant by subtracting 5 from both sides:

3x = 15

Then divide both sides by 3:

x = 5

Therefore, the solution is:

x = 5

Another Example

4x - 7 = 21

Add 7 to both sides:

4x = 28

Divide by 4:

x = 7

Multi-Step Linear Equations

A multi-step equation requires several operations to isolate the variable.

Example:

3x + 7 - x = 15

First, combine like terms:

2x + 7 = 15

Subtract 7 from both sides:

2x = 8

Divide by 2:

x = 4

Therefore:

x = 4

When solving multi-step equations, simplify each side first whenever possible before isolating the variable.

Variables on Both Sides

Some linear equations have variables on both sides of the equal sign.

Example:

5x + 3 = 2x + 15

Subtract 2x from both sides:

3x + 3 = 15

Subtract 3:

3x = 12

Divide by 3:

x = 4

Therefore, the solution is:

x = 4

A useful strategy is to move variable terms to one side and constants to the other side.

Linear Equations with Fractions

When an equation contains fractions, multiplying every term by the least common denominator (LCD) can remove the fractions.

Example:

x/3 + 2 = 6

Subtract 2 from both sides:

x/3 = 4

Multiply both sides by 3:

x = 12

Another Example

Consider:

x/2 + x/3 = 10

The LCD of 2 and 3 is 6.

Multiply every term by 6:

3x + 2x = 60

Combine like terms:

5x = 60

Divide by 5:

x = 12

Linear Equations with Decimals

Linear equations can also contain decimal numbers.

Example:

0.5x + 2 = 7

Subtract 2 from both sides:

0.5x = 5

Divide by 0.5:

x = 10

Another method is to multiply the entire equation by a power of 10 to remove the decimal.

For example:

0.5x + 2 = 7

Multiply every term by 10:

5x + 20 = 70

Subtract 20:

5x = 50

Divide by 5:

x = 10

Linear Equations with Parentheses

When an equation contains parentheses, use the distributive property to remove them.

Example:

3(x + 4) = 21

Distribute 3:

3x + 12 = 21

Subtract 12:

3x = 9

Divide by 3:

x = 3

Example with Parentheses on Both Sides

2(x + 3) = x + 9

Distribute:

2x + 6 = x + 9

Subtract x from both sides:

x + 6 = 9

Subtract 6:

x = 3

Special Cases of Linear Equations

Not every linear equation has exactly one solution. Some equations have no solution, while others have infinitely many solutions.

One Solution

Example:

2x + 4 = 10

This gives:

x = 3

There is exactly one solution.

No Solution

Consider:

2x + 5 = 2x + 9

Subtract 2x from both sides:

5 = 9

This statement is false, so there is no solution.

Infinitely Many Solutions

Consider:

3x + 6 = 3(x + 2)

Distribute:

3x + 6 = 3x + 6

This statement is true for every value of x.

Therefore, the equation has infinitely many solutions.

Checking a Solution

After solving an equation, substitute the answer back into the original equation to verify that both sides are equal.

Suppose we solved:

4x - 3 = 17

and obtained:

x = 5

Substitute 5 into the original equation:

4(5) - 3 = 17

20 - 3 = 17

17 = 17

Since both sides are equal, x = 5 is correct.

Checking the solution is a useful way to catch arithmetic or sign errors.

Linear Equation Word Problems

Linear equations can be used to represent real-life situations involving age, money, distance, quantities, and other relationships.

Example: Number Problem

A number increased by 8 is 20. What is the number?

Let x represent the unknown number.

Translate the statement into an equation:

x + 8 = 20

Subtract 8 from both sides:

x = 12

Therefore, the number is 12.

Example: Cost Problem

A student has ₱500 and spends ₱125. How much money remains?

Let x represent the remaining money.

The equation is:

x + 125 = 500

Subtract 125:

x = 375

Therefore, ₱375 remains.

When solving word problems, identify the unknown quantity, translate the information into an equation, solve it, and check whether the answer makes sense in the context of the problem.

Common Mistakes

Several mistakes commonly occur when solving linear equations.

1. Doing an Operation on Only One Side

An equation must remain balanced. If you add, subtract, multiply, or divide one side, perform the same operation on the other side.

2. Incorrectly Moving Terms

Instead of thinking that a term simply "moves" across the equal sign, remember that you are performing an operation on both sides.

3. Forgetting to Distribute

For:

3(x + 4)

the correct expansion is:

3x + 12

Both terms inside the parentheses must be multiplied by 3.

4. Sign Errors

Be especially careful when subtracting negative numbers or distributing a negative sign.

5. Not Checking the Answer

Substitute the solution into the original equation whenever possible to verify the result.

Summary

A linear equation is an equation in which the variable has a highest exponent of 1.

The main goal when solving a linear equation is to isolate the variable while keeping both sides of the equation equal.

Important concepts include:

• One-step equations – require one main operation to isolate the variable.

• Two-step equations – require two main operations.

• Multi-step equations – require several operations, often including combining like terms.

• Variables on both sides – move variable terms to one side and constants to the other.

• Equations with fractions – use the LCD when necessary to remove fractions.

• Equations with decimals – decimals can be eliminated by multiplying by an appropriate power of 10.

• Parentheses – use the distributive property to remove them.

Some equations have:

• One solution

• No solution

• Infinitely many solutions

A general strategy for solving linear equations is:

1. Simplify both sides.

2. Remove parentheses when necessary.

3. Combine like terms.

4. Move variable terms to one side.

5. Move constant terms to the other side.

6. Divide or multiply to isolate the variable.

7. Check the solution.

Mastering linear equations provides an important foundation for algebra, functions, graphs, and more advanced mathematical problem solving.
