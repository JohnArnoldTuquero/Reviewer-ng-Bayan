What is a Quadratic Equation?

A quadratic equation is an equation in which the highest power of the variable is 2.

Examples of quadratic equations include:

x2 + 5x + 6 = 0

2x2 - 7x + 3 = 0

x2 - 16 = 0

Quadratic equations can have two real solutions, one real solution, or no real solutions. They may also have complex solutions.

Why Are Quadratic Equations Important?

Quadratic equations are used to describe many mathematical situations involving areas, motion, dimensions, and other relationships where a variable is squared.

Standard Form of a Quadratic Equation

The standard form of a quadratic equation is:

ax2 + bx + c = 0

where a, b, and c are constants and:

a ≠ 0

The value of a cannot be zero because if a = 0, the x2 term disappears and the equation becomes linear.

Example

Consider:

2x2 + 5x - 3 = 0

Here:

a = 2

b = 5

c = -3

Parts of a Quadratic Equation

A quadratic equation in standard form has three main coefficients:

ax2 + bx + c = 0

Coefficient a

The coefficient a is attached to x2. It determines the quadratic term and affects the shape and direction of the graph.

Coefficient b

The coefficient b is attached to x. It is the coefficient of the linear term.

Constant c

The value c is the constant term. It has no variable attached to it.

For:

3x2 - 8x + 4 = 0

a = 3, b = -8, and c = 4.

Quadratic, Linear, and Constant Terms

A quadratic equation can contain three types of terms.

Quadratic Term

The quadratic term contains x2.

Example:

4x2

Linear Term

The linear term contains x raised to the first power.

Example:

-7x

Constant Term

The constant term contains no variable.

Example:

12

Therefore, in:

4x2 - 7x + 12 = 0

4x2 is the quadratic term, -7x is the linear term, and 12 is the constant term.

Solving Quadratic Equations

Solving a quadratic equation means finding the value or values of x that make the equation true.

Several methods can be used to solve quadratic equations:

1. Factoring

2. Taking square roots

3. Completing the square

4. Quadratic formula

The most convenient method depends on the form of the equation.

First Step

Whenever possible, rewrite the equation in standard form:

ax2 + bx + c = 0

Solving by Factoring

Factoring is one of the most common methods for solving quadratic equations.

Consider:

x2 + 5x + 6 = 0

Find two numbers whose product is 6 and whose sum is 5.

The numbers are 2 and 3.

Therefore:

(x + 2)(x + 3) = 0

Set each factor equal to zero:

x + 2 = 0

x + 3 = 0

Therefore:

x = -2

x = -3

The solutions are -2 and -3.

Zero Product Property

The Zero Product Property states that if the product of two or more factors is zero, then at least one of the factors must be zero.

In other words:

If AB = 0, then:

A = 0 or B = 0

This property is important when solving quadratic equations by factoring.

Example

Consider:

(x - 4)(x + 2) = 0

Set each factor equal to zero:

x - 4 = 0

x + 2 = 0

Therefore:

x = 4

x = -2

Solving by Taking Square Roots

When a quadratic equation contains a squared variable without a linear term, taking square roots can be a convenient method.

Consider:

x2 = 25

Take the square root of both sides:

x = ±5

Therefore:

x = 5

or

x = -5

Important

When taking the square root of a positive number in an equation such as x2 = 25, remember both the positive and negative values because both 52 and (-5)2 equal 25.

Completing the Square

Completing the square is a method that rewrites a quadratic expression as a perfect square.

Consider:

x2 + 6x + 5 = 0

Move the constant:

x2 + 6x = -5

Take half of the coefficient of x:

6 ÷ 2 = 3

Square it:

32 = 9

Add 9 to both sides:

x2 + 6x + 9 = 4

Factor the left side:

(x + 3)2 = 4

Take the square root:

x + 3 = ±2

Therefore:

x = -1

or

x = -5

Quadratic Formula

The quadratic formula can be used to solve any quadratic equation written in standard form:

ax2 + bx + c = 0

The formula is:

x = (-b ± √(b2 - 4ac)) / 2a

Example

Solve:

x2 - 5x + 6 = 0

Identify the coefficients:

a = 1

b = -5

c = 6

Substitute them into the formula:

x = (5 ± √((-5)2 - 4(1)(6))) / 2

Simplify:

x = (5 ± √(25 - 24)) / 2

x = (5 ± 1) / 2

Therefore:

x = 3

or

x = 2

The Discriminant

The expression inside the square root of the quadratic formula is called the discriminant.

For:

ax2 + bx + c = 0

the discriminant is:

D = b2 - 4ac

The value of the discriminant tells us about the number and type of real solutions.

Positive Discriminant

If:

D > 0

the quadratic has two distinct real solutions.

Zero Discriminant

If:

D = 0

the quadratic has one real solution, which is a repeated root.

Negative Discriminant

If:

D < 0

there are no real solutions. The solutions are complex.

Nature of the Roots

The solutions of a quadratic equation are also called its roots or zeros.

The discriminant can be used to determine the nature of these roots.

Two Real Roots

If b2 - 4ac is positive, there are two distinct real roots.

One Real Root

If b2 - 4ac equals zero, there is one repeated real root.

No Real Roots

If b2 - 4ac is negative, there are no real roots.

A negative discriminant produces the square root of a negative number in the quadratic formula, leading to complex solutions.

Vertex of a Quadratic

A quadratic function can be written as:

y = ax2 + bx + c

Its graph is a parabola. The highest or lowest point of the parabola is called the vertex.

The x-coordinate of the vertex is:

x = -b / 2a

Example

Consider:

y = x2 - 4x + 3

Here:

a = 1

b = -4

Therefore:

x = -(-4) / 2(1) = 2

Substitute x = 2:

y = 22 - 4(2) + 3

y = 4 - 8 + 3

y = -1

Therefore, the vertex is (2, -1).

Graphing Quadratic Equations

The graph of a quadratic function is called a parabola.

A quadratic equation in the form:

y = ax2 + bx + c

produces a parabola.

Direction of the Parabola

If a > 0, the parabola opens upward.

If a < 0, the parabola opens downward.

x-Intercepts

The x-intercepts are the points where the graph crosses or touches the x-axis. They correspond to the real solutions of the quadratic equation.

y-Intercept

The y-intercept occurs when x = 0. In the equation:

y = ax2 + bx + c

the y-intercept is c.

Quadratic Equation Word Problems

Quadratic equations can be used to solve problems involving area, dimensions, motion, and other situations where a squared variable naturally occurs.

Example: Area

Suppose a rectangular garden has a width of x meters and a length of x + 3 meters. If its area is 40 square meters, then:

x(x + 3) = 40

Expand:

x2 + 3x = 40

Move everything to one side:

x2 + 3x - 40 = 0

Factor:

(x + 8)(x - 5) = 0

Therefore:

x = -8 or x = 5.

Since a physical length cannot be negative, x = 5 is the meaningful solution.

The width is 5 meters and the length is 8 meters.

Checking Solutions

After solving a quadratic equation, substitute each solution into the original equation to make sure it satisfies the equation.

Consider:

x2 - 5x + 6 = 0

The solutions are x = 2 and x = 3.

Check x = 2

22 - 5(2) + 6 = 0

4 - 10 + 6 = 0

0 = 0

Check x = 3

32 - 5(3) + 6 = 0

9 - 15 + 6 = 0

0 = 0

Both solutions are correct.

Common Mistakes

Forgetting the ±

When solving x2 = a by taking square roots, remember that both positive and negative roots may be solutions.

Incorrect Signs in the Quadratic Formula

Pay close attention to the signs of a, b, and c when substituting into the quadratic formula.

Not Writing the Equation in Standard Form

Before using the quadratic formula, make sure the equation is arranged as:

ax2 + bx + c = 0

Forgetting Both Solutions

The quadratic formula contains ±, so it usually produces two possible values. Check both values unless the discriminant is zero.

Accepting Impossible Word-Problem Values

In real-world problems, a negative length, negative number of objects, or other impossible value may need to be rejected based on the context.

Summary

A quadratic equation is an equation whose highest exponent is 2.

Its standard form is:

ax2 + bx + c = 0

Common methods for solving quadratic equations include:

1. Factoring – rewrite the quadratic as a product of factors and use the Zero Product Property.

2. Taking square roots – isolate the squared variable and take the positive and negative square roots.

3. Completing the square – rewrite the quadratic as a perfect square.

4. Quadratic formula – use x = (-b ± √(b2 - 4ac)) / 2a.

The discriminant:

b2 - 4ac

helps determine the number of real solutions.

A positive discriminant gives two distinct real solutions, a zero discriminant gives one repeated real solution, and a negative discriminant gives no real solutions.

Quadratic equations are also represented graphically by parabolas and can be applied to problems involving areas, dimensions, motion, and other real-world situations.
