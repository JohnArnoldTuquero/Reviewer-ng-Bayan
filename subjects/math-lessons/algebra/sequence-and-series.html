What is a Sequence?

A sequence is an ordered list of numbers that follows a particular rule or pattern. Each number in a sequence is called a term.

For example:

2, 4, 6, 8, 10, ...

This sequence follows the pattern of adding 2 to each term. The numbers 2, 4, 6, 8, and 10 are the terms of the sequence.

A sequence can be written as:

a1, a2, a3, a4, ...

where an represents the nth term of the sequence.

Terms of a Sequence

The individual numbers in a sequence are called terms. The position of a term is indicated by its subscript.

For example, consider:

5, 10, 15, 20, 25, ...

We can identify the terms as:

a1 = 5
a2 = 10
a3 = 15
a4 = 20
a5 = 25

The subscript tells us the position of the term in the sequence.

Finding the Pattern

To work with a sequence, first look for the rule connecting one term to the next.

Example:

3, 6, 9, 12, 15, ...

Each term increases by 3.

Another example:

2, 6, 18, 54, ...

Each term is multiplied by 3.

Common patterns include:

  • Adding the same number
  • Subtracting the same number
  • Multiplying by the same number
  • Dividing by the same number
  • Other mathematical patterns

Finite and Infinite Sequences

A finite sequence has a definite number of terms.

Example:

4, 8, 12, 16, 20

This sequence has five terms.

An infinite sequence continues indefinitely and is usually represented using three dots.

Example:

4, 8, 12, 16, 20, ...

The dots indicate that the sequence continues.

Arithmetic Sequence

An arithmetic sequence is a sequence in which the difference between consecutive terms is always the same.

For example:

5, 8, 11, 14, 17, ...

The difference between consecutive terms is:

8 - 5 = 3
11 - 8 = 3
14 - 11 = 3

Since the difference is always 3, this is an arithmetic sequence.

Common Difference

The fixed difference between consecutive terms of an arithmetic sequence is called the common difference.

The common difference is represented by d.

It can be found using:

d = a2 - a1

For the sequence:

12, 17, 22, 27, ...

The common difference is:

d = 17 - 12 = 5

A common difference can also be negative.

Example:

20, 16, 12, 8, ...

Here:

d = 16 - 20 = -4

Arithmetic Sequence Formula

The nth term of an arithmetic sequence can be found using:

an = a1 + (n - 1)d

where:

  • an = nth term
  • a1 = first term
  • n = position of the term
  • d = common difference

This formula is useful when you need to find a term far into the sequence without listing every term.

Finding the nth Term of an Arithmetic Sequence

Consider the sequence:

4, 7, 10, 13, ...

We want to find the 20th term.

First identify:

a1 = 4
d = 3
n = 20

Use the formula:

an = a1 + (n - 1)d

Substitute:

a20 = 4 + (20 - 1)(3)

a20 = 4 + 57

a20 = 61

Therefore, the 20th term is 61.

Geometric Sequence

A geometric sequence is a sequence in which each term is obtained by multiplying the previous term by the same number.

For example:

3, 6, 12, 24, 48, ...

Each term is multiplied by 2.

Another example is:

81, 27, 9, 3, 1, ...

Each term is multiplied by 1/3.

Common Ratio

The fixed number used to multiply one term to obtain the next term is called the common ratio.

The common ratio is represented by r.

It can be found using:

r = a2 / a1

For example:

5, 15, 45, 135, ...

The common ratio is:

r = 15 / 5 = 3

Therefore, each term is multiplied by 3.

Geometric Sequence Formula

The nth term of a geometric sequence can be found using:

an = a1rn-1

where:

  • an = nth term
  • a1 = first term
  • r = common ratio
  • n = position of the term

Finding the nth Term of a Geometric Sequence

Consider:

2, 6, 18, 54, ...

We want to find the 6th term.

Identify:

a1 = 2
r = 3
n = 6

Use:

an = a1rn-1

Substitute:

a6 = 2(3)6-1

a6 = 2(35)

a6 = 486

Therefore, the 6th term is 486.

What is a Series?

A series is formed when the terms of a sequence are added together.

For example, the sequence:

2, 4, 6, 8, 10

forms the series:

2 + 4 + 6 + 8 + 10

A sequence lists numbers in order, while a series involves adding those numbers.

Arithmetic Series

An arithmetic series is the sum of the terms of an arithmetic sequence.

For example:

5 + 8 + 11 + 14 + 17

The terms form an arithmetic sequence because the common difference is 3.

The series is the sum of these terms.

Sum of an Arithmetic Series

The sum of the first n terms of an arithmetic series can be found using:

Sn = n/2 (a1 + an)

Another form is:

Sn = n/2 [2a1 + (n - 1)d]

where:

  • Sn = sum of the first n terms
  • n = number of terms
  • a1 = first term
  • an = nth term
  • d = common difference

Example

Find the sum of:

3 + 6 + 9 + 12 + 15

Here:

n = 5
a1 = 3
an = 15

Therefore:

S5 = 5/2 (3 + 15)

S5 = 5/2 (18)

S5 = 45

The sum is 45.

Geometric Series

A geometric series is the sum of the terms of a geometric sequence.

For example:

2 + 6 + 18 + 54

The common ratio is 3, so the terms form a geometric sequence and their sum forms a geometric series.

Sum of a Geometric Series

The sum of the first n terms of a finite geometric series can be found using:

Sn = a1(1 - rn) / (1 - r)

where:

  • Sn = sum of the first n terms
  • a1 = first term
  • r = common ratio
  • n = number of terms

Example

Find the sum:

2 + 6 + 18 + 54

Identify:

a1 = 2
r = 3
n = 4

Use the formula:

S4 = 2(1 - 34) / (1 - 3)

S4 = 2(1 - 81) / (-2)

S4 = 80

Therefore, the sum is 80.

Sequence and Series Word Problems

Sequences and series can be used to solve problems involving repeated patterns, payments, savings, arrangements, and other quantities that change regularly.

Example 1: Arithmetic Sequence

A student saves ₱100 during the first week and increases the amount saved by ₱50 every week. How much will the student save during the 10th week?

Identify:

a1 = 100
d = 50
n = 10

Use:

an = a1 + (n - 1)d

a10 = 100 + (10 - 1)(50)

a10 = 550

The amount saved during the 10th week is ₱550.

Example 2: Arithmetic Series

If the student wants to know the total amount saved during the first 10 weeks, an arithmetic series can be used.

The first term is ₱100 and the 10th term is ₱550.

S10 = 10/2 (100 + 550)

S10 = 5(650)

S10 = 3,250

The total amount saved is ₱3,250.

Common Mistakes

When solving sequence and series problems, avoid these common mistakes:

  • Confusing a sequence with a series.
  • Using the common difference for a geometric sequence.
  • Using the common ratio for an arithmetic sequence.
  • Forgetting that the first term is represented by a1.
  • Using n incorrectly when finding the nth term.
  • Forgetting the exponent n - 1 in the geometric sequence formula.
  • Using a sequence formula when the problem asks for a sum.
  • Failing to check whether the pattern is arithmetic or geometric.

A good first step is to determine whether the problem involves a difference, a ratio, or a sum.

Summary

A sequence is an ordered list of numbers that follows a pattern, while a series is the sum of the terms of a sequence.

An arithmetic sequence has a constant common difference:

an = a1 + (n - 1)d

An arithmetic series can be summed using:

Sn = n/2 (a1 + an)

A geometric sequence has a constant common ratio:

an = a1rn-1

A finite geometric series can be summed using:

Sn = a1(1 - rn) / (1 - r)

Remember:

  • Sequence → ordered list of terms
  • Series → sum of terms
  • Arithmetic → constant difference
  • Geometric → constant ratio
