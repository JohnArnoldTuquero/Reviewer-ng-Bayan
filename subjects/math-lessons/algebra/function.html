What is a Function?

A function is a special relationship between two sets of values in which every input has exactly one output.

The input is commonly represented by x, while the output is represented by y or f(x).

For example:

f(x) = 2x + 1

If the input is x = 3, then:

f(3) = 2(3) + 1

f(3) = 7

Therefore, the input 3 produces exactly one output, 7.

The most important rule to remember is:

One input can have only one output.

Relations and Functions

A relation is any set of ordered pairs that connects inputs and outputs.

For example:

{(1, 2), (2, 4), (3, 6)}

This relation is also a function because each input appears with only one output.

Consider:

{(1, 2), (2, 4), (1, 5)}

This is not a function because the input 1 is connected to two different outputs: 2 and 5.

Important Difference

Every function is a relation, but not every relation is a function.

Parts of a Function

A function can be described using several important terms.

Input

The input is the value that is placed into the function. It is commonly represented by x.

Output

The output is the value produced by the function. It is commonly represented by y or f(x).

Independent Variable

The input variable is usually called the independent variable.

Dependent Variable

The output variable is usually called the dependent variable because its value depends on the input.

For example:

y = 3x + 2

Here, x is the independent variable and y is the dependent variable.

Domain

The domain of a function is the set of all possible input values.

For example, consider:

{(1, 3), (2, 5), (3, 7)}

The inputs are 1, 2, and 3.

Therefore, the domain is:

{1, 2, 3}

Restrictions on the Domain

Some functions cannot accept every real number as an input.

For example:

f(x) = 1/(x - 2)

The denominator cannot be zero:

x - 2 ≠ 0

Therefore:

x ≠ 2

So 2 is excluded from the domain.

Range

The range of a function is the set of all possible output values.

For example:

{(1, 3), (2, 5), (3, 7)}

The outputs are 3, 5, and 7.

Therefore, the range is:

{3, 5, 7}

The domain contains the input values, while the range contains the output values.

Remember:

Domain → inputs

Range → outputs

Function Notation

Functions are often written using function notation.

Instead of writing:

y = 2x + 3

we can write:

f(x) = 2x + 3

The notation f(x) means the output of function f when the input is x.

For example:

f(x) = x2 + 4

Other functions can be named differently:

g(x) = 3x - 2

h(x) = x + 7

The letter before the parentheses identifies the function.

Evaluating Functions

To evaluate a function, substitute the given input value for the variable.

Example:

f(x) = 3x + 2

Find f(4).

Substitute 4 for x:

f(4) = 3(4) + 2

Multiply:

f(4) = 12 + 2

Therefore:

f(4) = 14

Another Example

Given:

f(x) = x2 - 5x + 6

Find f(2).

f(2) = 22 - 5(2) + 6

f(2) = 4 - 10 + 6

f(2) = 0

Representations of Functions

A function can be represented in several different ways.

1. Equation

Example:

f(x) = 2x + 1

2. Ordered Pairs

Example:

{(1, 3), (2, 5), (3, 7)}

3. Table

A table can list each input and its corresponding output.

4. Mapping Diagram

A mapping diagram uses arrows to connect inputs to outputs.

5. Graph

A function can also be shown visually on a coordinate plane.

These representations describe the same relationship in different forms.

Mapping Diagrams

A mapping diagram represents a relation by showing arrows from input values to output values.

For example, suppose:

1 → 3

2 → 5

3 → 7

Each input has exactly one arrow pointing to an output, so the relation is a function.

Not a Function

If one input points to two different outputs, the relation is not a function.

For example:

1 → 3

1 → 5

Since the input 1 has two outputs, this relation is not a function.

Functions from Tables

A function can be represented using a table of input and output values.

For example:

x: 1, 2, 3, 4
f(x): 3, 5, 7, 9

Each input has one corresponding output.

Looking at the pattern, the function can be written as:

f(x) = 2x + 1

Tables are useful for identifying patterns and checking whether a relation represents a function.

Functions from Graphs

A function can be represented on a coordinate plane by plotting ordered pairs.

The horizontal axis represents the input, usually x, while the vertical axis represents the output, usually y.

For example, the function:

y = 2x + 1

produces points such as:

(0, 1)

(1, 3)

(2, 5)

Plotting these points creates the graph of the function.

The graph provides a visual way to see how the output changes as the input changes.

Vertical Line Test

The vertical line test is a graphical method for determining whether a graph represents a function.

Imagine drawing vertical lines across the graph.

If any vertical line intersects the graph at more than one point, the graph is not a function.

If every vertical line intersects the graph at most once, the graph represents a function.

Why It Works

A function allows each input value to have only one output value.

A vertical line represents one particular x-value. If it crosses the graph more than once, that input would have multiple outputs.

Linear Functions

A linear function is a function whose graph is a straight line.

A common form is:

f(x) = mx + b

where:

m is the slope.

b is the y-intercept.

Example:

f(x) = 2x + 3

The slope is 2 and the y-intercept is 3.

Linear functions have a constant rate of change.

Quadratic Functions

A quadratic function is a function that contains a variable raised to the second power.

The standard form is:

f(x) = ax2 + bx + c

where a ≠ 0.

Example:

f(x) = x2 - 4x + 3

The graph of a quadratic function is called a parabola.

Quadratic functions are different from linear functions because their rate of change is not constant.

Operations on Functions

Functions can be combined using addition, subtraction, multiplication, and division.

Addition

If:

f(x) = x + 2

g(x) = 3x

then:

(f + g)(x) = f(x) + g(x)

(f + g)(x) = x + 2 + 3x

(f + g)(x) = 4x + 2

Subtraction

(f - g)(x) = f(x) - g(x)

Multiplication

(fg)(x) = f(x)g(x)

Division

(f/g)(x) = f(x)/g(x)

For division, values that make the denominator zero must be excluded from the domain.

Composition of Functions

Composition of functions means using the output of one function as the input of another function.

It is written as:

(f ∘ g)(x) = f(g(x))

Suppose:

f(x) = 2x + 1

g(x) = x + 3

Find f(g(x)).

Start with:

f(g(x)) = 2g(x) + 1

Substitute g(x) = x + 3:

f(g(x)) = 2(x + 3) + 1

Simplify:

f(g(x)) = 2x + 7

The order matters. In general:

f(g(x)) ≠ g(f(x))

Function Word Problems

Functions are useful for describing real-world relationships between quantities.

Example: Cost

Suppose a store charges a fixed fee of ₱50 plus ₱20 for every item purchased.

If x represents the number of items, the total cost can be represented by:

C(x) = 20x + 50

If 5 items are purchased:

C(5) = 20(5) + 50

C(5) = 100 + 50

C(5) = ₱150

Identifying the Variables

When solving function word problems:

1. Identify the input.

2. Identify the output.

3. Write the relationship as a function.

4. Substitute the required input value.

5. Interpret the output in the context of the problem.

Common Mistakes

1. Confusing domain and range

The domain contains input values, while the range contains output values.

2. Thinking every relation is a function

A relation is not a function if one input has more than one output.

3. Substituting incorrectly

When evaluating a function, replace the variable everywhere it appears.

4. Forgetting parentheses

If the input is negative, use parentheses when substituting.

For example:

f(x) = x2

For x = -3:

f(-3) = (-3)2 = 9

5. Forgetting domain restrictions

Functions involving denominators, radicals, or other restrictions may not accept every real number as an input.

6. Reversing function composition

Remember that f(g(x)) means evaluate g(x) first, then use its result as the input of f.

Summary

A function is a relation in which every input has exactly one output.

The domain is the set of possible input values, while the range is the set of possible output values.

Function notation is commonly written as:

f(x)

To evaluate a function, substitute the given input value into the function.

Functions can be represented using equations, ordered pairs, tables, mapping diagrams, and graphs.

The vertical line test can determine whether a graph represents a function.

Linear functions have straight-line graphs and are commonly written as:

f(x) = mx + b

Quadratic functions contain an x2 term and have parabolic graphs.

Functions can be combined using addition, subtraction, multiplication, and division.

Composition of functions means using the output of one function as the input of another:

(f ∘ g)(x) = f(g(x))

When solving function problems, always identify the input, output, domain, and any restrictions that apply.
