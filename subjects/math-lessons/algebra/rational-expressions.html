What is a Rational Expression?

A rational expression is an algebraic expression that can be written as the quotient of two polynomials. In other words, it has a polynomial in the numerator and a polynomial in the denominator.

The general form of a rational expression is:

P(x) / Q(x)

where P(x) and Q(x) are polynomials and Q(x) ≠ 0.

Examples of rational expressions include:

3/x
(x + 2)/(x - 5)
(x2 - 9)/(x + 3)

Rational expressions are similar to ordinary fractions. The main difference is that variables and algebraic expressions can appear in the numerator and denominator.

Parts of a Rational Expression

Consider the rational expression:

(x + 3)/(x - 2)

Numerator

The expression on top is called the numerator.

In this example, the numerator is:

x + 3

Denominator

The expression on the bottom is called the denominator.

In this example, the denominator is:

x - 2

The denominator is especially important because it cannot be equal to zero.

Restrictions and Domain

A rational expression is undefined whenever its denominator is zero.

For example:

1/(x - 4)

Set the denominator equal to zero:

x - 4 = 0

Therefore:

x = 4

This means x = 4 is not allowed.

The restriction is:

x ≠ 4

The domain of a rational expression consists of all values of the variable that make the expression defined.

Always check the original denominator when determining restrictions.

Simplifying Rational Expressions

To simplify a rational expression, factor the numerator and denominator and then cancel common factors.

Consider:

(x2 - 9)/(x + 3)

Factor the numerator:

x2 - 9 = (x - 3)(x + 3)

Therefore:

((x - 3)(x + 3))/(x + 3)

Cancel the common factor:

x - 3

However, the original denominator cannot be zero, so:

x ≠ -3

The simplified expression is therefore:

x - 3, where x ≠ -3

Finding Common Factors

Before simplifying a rational expression, factor both the numerator and denominator.

For example:

(x2 + 5x + 6)/(x2 + 3x + 2)

Factor the numerator:

x2 + 5x + 6 = (x + 2)(x + 3)

Factor the denominator:

x2 + 3x + 2 = (x + 1)(x + 2)

So:

((x + 2)(x + 3))/((x + 1)(x + 2))

Cancel the common factor x + 2:

(x + 3)/(x + 1)

The original denominator gives the restrictions:

x ≠ -1 and x ≠ -2

Multiplying Rational Expressions

To multiply rational expressions:

1. Factor all numerators and denominators.
2. Cancel common factors.
3. Multiply the remaining factors.

Example:

(x/3) × (6/(x + 2))

Cancel the common factor 3:

2x/(x + 2)

Therefore:

(x/3) × (6/(x + 2)) = 2x/(x + 2)

The restriction is:

x ≠ -2

Dividing Rational Expressions

To divide rational expressions, use the Keep-Change-Flip idea:

1. Keep the first expression.
2. Change division to multiplication.
3. Flip the second fraction.

Example:

(x/4) ÷ (2/(x + 3))

Change division to multiplication and flip the second fraction:

(x/4) × ((x + 3)/2)

Multiply:

x(x + 3)/8

Therefore:

(x/4) ÷ (2/(x + 3)) = x(x + 3)/8

Remember that the original denominator cannot be zero, and the divisor itself cannot be zero.

Adding Rational Expressions with the Same Denominator

When rational expressions have the same denominator, add their numerators and keep the denominator.

Example:

3/(x + 2) + 5/(x + 2)

Add the numerators:

(3 + 5)/(x + 2)

Therefore:

8/(x + 2)

The restriction is:

x ≠ -2

Adding Rational Expressions with Different Denominators

When denominators are different, find a common denominator before adding.

Example:

1/x + 1/(x + 2)

The common denominator is:

x(x + 2)

Rewrite each fraction:

(x + 2)/(x(x + 2)) + x/(x(x + 2))

Add the numerators:

(x + 2 + x)/(x(x + 2))

Simplify:

(2x + 2)/(x(x + 2))

The restrictions are:

x ≠ 0 and x ≠ -2

Subtracting Rational Expressions

Subtracting rational expressions follows the same basic process as addition.

If the denominators are the same, subtract the numerators.

Example:

7/(x - 1) - 3/(x - 1)

Subtract the numerators:

(7 - 3)/(x - 1)

Therefore:

4/(x - 1)

The restriction is:

x ≠ 1

When denominators are different, find the least common denominator first.

Least Common Denominator

The least common denominator (LCD) is the smallest expression that can be used as a common denominator for all the rational expressions in a problem.

Example:

1/(x + 1) + 2/(x - 1)

The denominators are x + 1 and x - 1.

The LCD is:

(x + 1)(x - 1)

Rewrite each fraction using the LCD:

(x - 1)/((x + 1)(x - 1)) + 2(x + 1)/((x + 1)(x - 1))

Combine the numerators:

(x - 1 + 2x + 2)/((x + 1)(x - 1))

Therefore:

(3x + 1)/((x + 1)(x - 1))

The restrictions are:

x ≠ -1 and x ≠ 1

Complex Rational Expressions

A complex rational expression is a rational expression that contains one or more fractions within a larger fraction.

For example:

(1/x) / (2/x)

Rewrite the complex fraction as division:

(1/x) ÷ (2/x)

Change division to multiplication and flip the second fraction:

(1/x) × (x/2)

Cancel x:

1/2

Restrictions from the original expression still apply. In this example, x ≠ 0.

Evaluating Rational Expressions

To evaluate a rational expression, substitute the given value of the variable into the expression and simplify.

Example:

Evaluate:

(x + 2)/(x - 1)

when x = 3.

Substitute 3:

(3 + 2)/(3 - 1)

Simplify:

5/2

Therefore, the value of the rational expression is:

5/2

Always check that the given value does not make the denominator zero.

Operations with Rational Expressions

The four basic operations with rational expressions are:

Addition — Find a common denominator, combine the numerators, and simplify.

Subtraction — Find a common denominator, subtract the numerators, and simplify.

Multiplication — Factor, cancel common factors, and multiply.

Division — Keep the first expression, change division to multiplication, and flip the second expression.

Important Rule

For every operation, check the restrictions from the original expressions. A canceled factor does not mean its original restriction disappears.

Rational Expression Word Problems

Rational expressions can be used to represent rates, proportions, work problems, and other situations involving division.

Example: Rate

Suppose a vehicle travels a distance d in a time t. Its speed can be represented by:

Speed = d/t

Since time appears in the denominator, t ≠ 0.

Example: Work Rate

If one person can complete a job in x hours, the person's work rate can be represented by:

1/x

When several people work together, their individual rates can be added to find the combined work rate.

When solving word problems, first identify what each variable represents and determine any values that are not allowed.

Common Mistakes

1. Canceling terms instead of factors

You can cancel common factors, but you cannot cancel individual terms separated by addition or subtraction.

For example, in:

(x + 2)/x

the x cannot simply be canceled because the numerator is a sum.

2. Forgetting restrictions

If a denominator can equal zero, that value must be excluded.

3. Adding denominators

When adding fractions, do not add the denominators.

For example:

1/3 + 1/3 = 2/3

not 2/6.

4. Forgetting to factor

Factoring first often makes simplification much easier.

5. Forgetting to flip when dividing

When dividing rational expressions, multiply by the reciprocal of the second expression.

Summary

A rational expression is a quotient of two polynomials.

The denominator of a rational expression can never be zero.

To simplify rational expressions, factor the numerator and denominator and cancel common factors.

To multiply rational expressions, factor, cancel, and multiply.

To divide rational expressions, multiply by the reciprocal of the divisor.

To add or subtract rational expressions with different denominators, find a common denominator first.

The least common denominator (LCD) helps combine rational expressions with different denominators.

When evaluating a rational expression, substitute the value of the variable and make sure the denominator is not zero.

Always keep track of the restrictions from the original expression, even after simplifying.
