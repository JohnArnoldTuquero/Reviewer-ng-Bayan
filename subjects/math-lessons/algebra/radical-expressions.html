What is a Radical Expression?

A radical expression is an algebraic expression that contains a radical symbol, such as a square root, cube root, or another root.

The most common radical is the square root, represented by the symbol √.

Examples of radical expressions include:

√9
√x
3√5
√(x + 4)
∛8

Radicals are closely related to exponents. For example:

√25 = 5

because:

52 = 25

Parts of a Radical Expression

Consider the radical:

3√(x + 5)

Radical Symbol

The symbol √ is called the radical symbol.

Index

The small number written on the upper-left side of the radical is called the index.

If there is no index shown, the index is understood to be 2.

Therefore:

√x = 2√x

Radicand

The expression inside the radical is called the radicand.

In √(x + 5), the radicand is:

x + 5

Coefficient

A number outside the radical is called the coefficient.

In 3√(x + 5), the coefficient is 3.

Square Roots

A square root of a number is a value that produces the original number when multiplied by itself.

For example:

√25 = 5

because:

5 × 5 = 25

Some common perfect square roots are:

√1 = 1
√4 = 2
√9 = 3
√16 = 4
√25 = 5
√36 = 6
√49 = 7
√64 = 8
√81 = 9
√100 = 10

The principal square root is normally taken to be the nonnegative root.

Cube Roots

A cube root of a number is a value that produces the original number when multiplied by itself three times.

The cube root symbol is:

∛

For example:

∛27 = 3

because:

3 × 3 × 3 = 27

Other examples include:

∛8 = 2
∛64 = 4
∛125 = 5
∛216 = 6

Unlike square roots, cube roots can be taken for both positive and negative numbers.

For example:

∛(-8) = -2

Index of a Radical

The index tells us which root is being taken.

Examples:

√x means the second root, or square root.
∛x means the third root, or cube root.
4√x means the fourth root.
5√x means the fifth root.

For example:

4√16 = 2

because:

24 = 16

If the index is not written, it is understood to be 2.

Perfect Squares and Perfect Cubes

A perfect square is a number that can be written as the square of an integer.

Examples:

1 = 12
4 = 22
9 = 32
16 = 42
25 = 52

A perfect cube is a number that can be written as the cube of an integer.

Examples:

1 = 13
8 = 23
27 = 33
64 = 43
125 = 53

Recognizing perfect squares and cubes makes simplifying radicals much easier.

Simplifying Radical Expressions

To simplify a radical, look for perfect powers inside the radicand.

Example:

√72

Factor 72:

72 = 36 × 2

Since 36 is a perfect square:

√72 = √(36 × 2)

Using the product property:

√72 = √36 × √2

Therefore:

√72 = 6√2

Another Example

Simplify:

√48

Since:

48 = 16 × 3

we get:

√48 = √16 × √3 = 4√3

Product Property of Radicals

The product property of radicals states that, under appropriate conditions:

√(ab) = √a × √b

This property can be used to separate a radical into simpler parts.

Example:

√50

Rewrite 50 as 25 × 2:

√50 = √(25 × 2)

Separate the radicals:

√25 × √2

Therefore:

√50 = 5√2

This property is especially useful when the radicand contains a perfect square factor.

Quotient Property of Radicals

The quotient property of radicals states that:

√(a/b) = √a / √b

when the expressions are defined.

Example:

√(25/9)

Separate the numerator and denominator:

√25 / √9

Simplify:

5/3

Therefore:

√(25/9) = 5/3

This property can also be used when simplifying radicals containing fractions.

Adding Radical Expressions

Radical expressions can be added or subtracted when they are like radicals.

Like radicals have the same index and the same radicand.

For example:

3√5 + 2√5

Since both terms contain √5, combine their coefficients:

(3 + 2)√5

Therefore:

3√5 + 2√5 = 5√5

Another Example

4√3 + 7√3 = 11√3

Only the coefficients are added. The radical part remains unchanged.

Subtracting Radical Expressions

Subtracting radicals follows the same principle as adding them. The radicals must be like radicals.

Example:

8√7 - 3√7

Subtract the coefficients:

(8 - 3)√7

Therefore:

8√7 - 3√7 = 5√7

Example with Simplification First

Consider:

√12 + √27

Simplify each radical:

√12 = 2√3

√27 = 3√3

Now combine like radicals:

2√3 + 3√3 = 5√3

Multiplying Radical Expressions

To multiply radical expressions, multiply the coefficients and multiply the radicands.

Example:

√3 × √6

Using the product property:

√18

Simplify:

√18 = 3√2

Therefore:

√3 × √6 = 3√2

Multiplying Coefficients

Consider:

2√5 × 3√10

Multiply the coefficients:

2 × 3 = 6

Multiply the radicals:

√5 × √10 = √50

Simplify:

6√50 = 30√2

Dividing Radical Expressions

When dividing radicals, the quotient property can be used.

Example:

√18 / √2

Combine the radicals:

√(18/2)

Simplify:

√9 = 3

Therefore:

√18 / √2 = 3

Example with Coefficients

6√20 / 2√5

Divide the coefficients:

6/2 = 3

Divide the radicals:

√20/√5 = √4 = 2

Therefore:

6√20 / 2√5 = 6

Rationalizing the Denominator

Rationalizing the denominator means rewriting a fraction so that there is no radical in the denominator.

Example:

1/√3

Multiply the numerator and denominator by √3:

(1 × √3)/(√3 × √3)

Since:

√3 × √3 = 3

the result is:

√3/3

Therefore:

1/√3 = √3/3

Binomial Denominator

If the denominator contains a binomial such as √a + b, its conjugate can be used to rationalize the denominator.

The conjugate of:

√a + b

is:

√a - b

Multiplying by the conjugate uses the difference of squares pattern.

Radicals and Rational Exponents

Radicals can be written using rational exponents.

The general relationship is:

n√(am) = am/n

For example:

√x = x1/2

A cube root can be written as:

∛x = x1/3

For example:

√(x3) = x3/2

This connection allows the laws of exponents to be used when working with radicals.

Radical Equations

A radical equation is an equation that contains a variable inside a radical.

Example:

√x = 5

Square both sides:

(√x)2 = 52

Therefore:

x = 25

Example with a Constant

Solve:

√(x + 1) = 4

Square both sides:

x + 1 = 16

Subtract 1:

x = 15

Always check the answer in the original equation because squaring both sides can sometimes introduce an extraneous solution.

Radical Expression Word Problems

Radical expressions appear in geometry, measurement, distance, and other mathematical applications.

Example: Distance

The distance formula between two points can involve a square root:

d = √((x2 - x1)2 + (y2 - y1)2)

Suppose the points are (1, 2) and (4, 6).

Substitute the values:

d = √((4 - 1)2 + (6 - 2)2)

Simplify:

d = √(32 + 42)

d = √(9 + 16)

d = √25

Therefore:

d = 5

Radical expressions are often useful when an exact answer is preferred instead of a decimal approximation.

Common Mistakes

1. Adding unlike radicals

Radicals cannot be combined unless they are like radicals.

For example:

√2 + √3

cannot be simplified by adding the radicands.

2. Adding inside the radical incorrectly

In general:

√(a + b) ≠ √a + √b

3. Forgetting to simplify first

Expressions that do not initially look like like radicals may become like radicals after simplification.

4. Leaving perfect powers inside the radical

For example:

√50

should be simplified to:

5√2

5. Forgetting to rationalize the denominator

When the expected final form requires a rational denominator, simplify the denominator by multiplying by an appropriate radical or conjugate.

6. Not checking radical equations

After solving a radical equation, substitute the answer back into the original equation to verify it.

Summary

A radical expression contains a radical symbol and may contain variables, numbers, or both.

The main parts of a radical are the index, radical symbol, radicand, and coefficient.

A square root has an index of 2, while a cube root has an index of 3.

To simplify radicals, factor the radicand and remove perfect powers from under the radical.

The product property allows radicals to be multiplied:

√(ab) = √a × √b

The quotient property allows radicals to be divided:

√(a/b) = √a / √b

Like radicals can be added and subtracted by combining their coefficients.

Radicals can be multiplied and divided using the properties of radicals.

Rationalizing the denominator removes radicals from the denominator of a fraction.

Radicals can also be expressed using rational exponents:

n√a = a1/n

When solving radical equations, isolate the radical, use an appropriate power to remove it, and always check the solution in the original equation.
