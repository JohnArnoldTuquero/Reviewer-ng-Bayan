What is a System of Linear Equations?

A system of linear equations is a set of two or more linear equations that contain the same variables.

The most common system contains two equations and two variables, usually x and y.

For example:

x + y = 10

x - y = 2

The goal is to find the values of x and y that make both equations true at the same time.

Example

Consider:

x + y = 7

x - y = 1

The solution is x = 4 and y = 3 because:

4 + 3 = 7

4 - 3 = 1

Parts of a System of Linear Equations

A system of linear equations contains equations, variables, coefficients, and constants.

Consider:

2x + 3y = 12

x - y = 1

Variables

The variables are the unknown quantities. In this system, the variables are x and y.

Coefficients

Coefficients are the numbers multiplied by variables. In 2x + 3y = 12, the coefficients are 2 and 3.

Constants

Constants are numbers without variables. In the first equation, 12 is the constant.

Solution of a System

A solution of a system is an ordered pair that satisfies every equation in the system.

Consider:

x + y = 8

x - y = 2

The ordered pair (5, 3) is a solution because:

5 + 3 = 8

5 - 3 = 2

Since both equations are true, (5, 3) is the solution of the system.

Important Idea

A value that satisfies only one equation is not enough. The solution must satisfy all equations in the system.

Ordered Pairs

A solution to a system of two linear equations is usually written as an ordered pair:

(x, y)

The first number represents x and the second number represents y.

For example:

(3, 5)

means:

x = 3

y = 5

Order Matters

The ordered pairs (3, 5) and (5, 3) are different.

Always substitute the first value for x and the second value for y.

Solving by Graphing

One way to solve a system is by graphing both equations on the same coordinate plane.

The solution is the point where the two lines intersect.

Consider:

y = x + 1

y = -x + 5

When the two lines are graphed, they intersect at:

(2, 3)

Therefore, x = 2 and y = 3 is the solution.

Why Graphing Works

Every point on a line represents a solution to its equation. The intersection point belongs to both lines, so it satisfies both equations.

Limitation of Graphing

Graphing can sometimes make the exact solution difficult to identify, especially when the lines intersect at a point that is not an integer. Algebraic methods can provide exact values more directly.

Solving by Substitution

The substitution method involves solving one equation for one variable and substituting that expression into the other equation.

Consider:

x + y = 10

x - y = 2

Step 1: Solve One Equation for a Variable

From the first equation:

x = 10 - y

Step 2: Substitute

Substitute x = 10 - y into the second equation:

(10 - y) - y = 2

Step 3: Solve

10 - 2y = 2

-2y = -8

y = 4

Step 4: Find x

Substitute y = 4 into x = 10 - y:

x = 6

Therefore, the solution is:

(6, 4)

Solving by Elimination

The elimination method solves a system by adding or subtracting the equations so that one variable is eliminated.

Consider:

x + y = 9

x - y = 3

Add the equations:

x + y + x - y = 9 + 3

2x = 12

Therefore:

x = 6

Substitute x = 6 into the first equation:

6 + y = 9

y = 3

The solution is:

(6, 3)

Addition Method

The addition method is a form of elimination where corresponding terms are added together to eliminate a variable.

Consider:

2x + y = 11

3x - y = 9

Add the equations:

2x + y + 3x - y = 11 + 9

5x = 20

Therefore:

x = 4

Substitute x = 4 into the first equation:

2(4) + y = 11

8 + y = 11

y = 3

Therefore:

(4, 3)

Multiplication Before Elimination

Sometimes the coefficients of a variable are not opposites. In that case, one or both equations can be multiplied by a number before using elimination.

Consider:

2x + 3y = 13

x + y = 5

To eliminate y, multiply the second equation by -3:

-3x - 3y = -15

Now add it to the first equation:

2x + 3y - 3x - 3y = 13 - 15

-x = -2

Therefore:

x = 2

Substitute x = 2 into x + y = 5:

2 + y = 5

y = 3

The solution is:

(2, 3)

Systems with Fractions

Systems of equations may contain fractions. One useful strategy is to multiply an entire equation by a common denominator to remove the fractions.

Consider:

x/2 + y = 5

x - y = 1

Multiply the first equation by 2:

x + 2y = 10

The system is now:

x + 2y = 10

x - y = 1

Subtract the second equation from the first:

3y = 9

y = 3

Substitute into x - y = 1:

x - 3 = 1

x = 4

Therefore, the solution is (4, 3).

Systems with Decimals

Systems may also contain decimal coefficients. Multiplying the equations by powers of 10 can remove the decimals.

Consider:

0.5x + y = 4

x - y = 2

Multiply the first equation by 2:

x + 2y = 8

Now solve the system:

x + 2y = 8

x - y = 2

Subtract the second equation from the first:

3y = 6

y = 2

Substitute y = 2:

x - 2 = 2

x = 4

The solution is (4, 2).

Special Cases

A system of linear equations does not always have exactly one solution. Depending on the relationship between the lines, a system can have one solution, no solution, or infinitely many solutions.

These cases can also be understood geometrically by looking at the graphs of the equations.

One Solution

A system has one solution when the two lines intersect at exactly one point.

For example:

y = x + 2

y = -x + 6

These lines have different slopes, so they intersect at one point.

Algebraically, solving the system produces one ordered pair.

No Solution

A system has no solution when the two lines are parallel and distinct.

Parallel lines have the same slope but different y-intercepts.

For example:

y = 2x + 3

y = 2x - 5

These lines never intersect, so there is no ordered pair that satisfies both equations.

Algebraic Indication

During elimination, a no-solution system may produce a false statement such as:

0 = 5

Since this statement is impossible, the system has no solution.

Infinitely Many Solutions

A system has infinitely many solutions when the two equations represent the same line.

For example:

x + y = 5

2x + 2y = 10

The second equation is simply twice the first equation. Both equations describe the same line.

Therefore, every point on that line satisfies both equations.

Algebraic Indication

During elimination, an infinitely many solution system may produce a true statement such as:

0 = 0

Systems of Equations Word Problems

Systems of equations are useful when a problem involves two unknown quantities and two relationships between them.

Example: Two Numbers

The sum of two numbers is 20. Their difference is 4. Let x and y represent the numbers.

The first statement gives:

x + y = 20

The second statement gives:

x - y = 4

Add the equations:

2x = 24

x = 12

Substitute into the first equation:

12 + y = 20

y = 8

Therefore, the two numbers are 12 and 8.

Setting Up Word Problems

A useful process is to identify the unknown quantities, assign variables, translate each condition into an equation, solve the system, and interpret the answer in the context of the problem.

Checking a Solution

Always check the ordered pair in both original equations.

Suppose the system is:

x + y = 9

x - y = 3

The proposed solution is (6, 3).

Check the first equation:

6 + 3 = 9

This is true.

Check the second equation:

6 - 3 = 3

This is also true.

Therefore, (6, 3) is the correct solution.

Common Mistakes

Solving Only One Equation

A solution must satisfy every equation in the system. Solving one equation alone is not enough.

Sign Errors

Be careful when subtracting equations or distributing negative signs. A single sign error can change the final solution.

Forgetting to Substitute Back

After finding one variable, substitute its value into one of the original equations to find the other variable.

Mixing Up the Ordered Pair

Remember that the solution is written as (x, y). Do not accidentally write (y, x).

Ignoring Special Cases

If elimination results in 0 = 0, the system has infinitely many solutions. If it results in a false statement such as 0 = 5, the system has no solution.

Summary

A system of linear equations consists of two or more linear equations involving the same variables.

The solution is the value or ordered pair that makes all equations true at the same time.

The main methods for solving systems include:

1. Graphing – graph both equations and find their intersection.

2. Substitution – solve one equation for a variable and substitute into the other equation.

3. Elimination – add or subtract equations to eliminate one variable.

4. Multiplication and Elimination – multiply one or both equations first when necessary, then eliminate a variable.

A system can have:

One solution – the lines intersect at one point.

No solution – the lines are parallel and distinct.

Infinitely many solutions – the equations represent the same line.

When solving systems, carefully manage signs, keep equations balanced, substitute values back into the original equations, and always interpret the final answer in the context of the problem.
