What is a Linear Inequality?

A linear inequality is a mathematical statement that compares two expressions using an inequality symbol. Unlike a linear equation, which states that two expressions are equal, a linear inequality describes a range of possible values.

A linear inequality usually contains a variable raised only to the first power. Examples include:

x + 4 > 9

2x - 3 ≤ 11

5x + 2 < 27

The goal when solving a linear inequality is to determine all values of the variable that make the statement true.

Equation vs. Inequality

An equation uses an equal sign:

x + 3 = 7

An inequality uses symbols such as:

x + 3 > 7

The equation usually has one specific solution, while an inequality can have many solutions.

Inequality Symbols

There are four main inequality symbols used in linear inequalities.

Greater Than (>)

The symbol > means "greater than."

x > 5

This means that x can be any number greater than 5.

Less Than (<)

The symbol < means "less than."

x < 5

This means that x can be any number less than 5.

Greater Than or Equal To (≥)

The symbol ≥ means "greater than or equal to."

x ≥ 5

This means that x can be 5 or any number greater than 5.

Less Than or Equal To (≤)

The symbol ≤ means "less than or equal to."

x ≤ 5

This means that x can be 5 or any number less than 5.

Solution of a Linear Inequality

The solution of an inequality is the set of all values that make the inequality true.

Consider:

x + 2 > 6

Subtract 2 from both sides:

x > 4

Therefore, every number greater than 4 is a solution.

Examples of solutions include 5, 6, 10, and 100. The number 4 itself is not included because the inequality is strictly greater than 4.

Checking a Solution

To check whether a number is a solution, substitute it into the original inequality.

For x + 2 > 6, test x = 7:

7 + 2 > 6

9 > 6

This is true, so 7 is a solution.

Linear Inequalities on the Number Line

Inequalities can be represented visually on a number line.

Open Circle

Use an open circle when the endpoint is not included. This is used for < and >.

For example:

x > 3

The circle is placed at 3, but 3 is not included. The solution extends to the right.

Closed Circle

Use a closed circle when the endpoint is included. This is used for ≤ and ≥.

For example:

x ≥ 3

The circle is placed at 3 and 3 is included. The solution extends to the right.

Direction on the Number Line

If the solution is greater than a number, shade or extend to the right.

If the solution is less than a number, shade or extend to the left.

One-Step Linear Inequalities

One-step inequalities can be solved by performing one operation on both sides.

Addition

Solve:

x - 5 > 2

Add 5 to both sides:

x > 7

Subtraction

Solve:

x + 4 ≤ 10

Subtract 4 from both sides:

x ≤ 6

Multiplication

Solve:

x/3 > 4

Multiply both sides by 3:

x > 12

Division

Solve:

5x ≤ 25

Divide both sides by 5:

x ≤ 5

Two-Step Linear Inequalities

Two-step inequalities require two inverse operations to isolate the variable.

Consider:

2x + 3 > 11

First, subtract 3 from both sides:

2x > 8

Then divide both sides by 2:

x > 4

Another Example

Solve:

4x - 7 ≤ 13

Add 7:

4x ≤ 20

Divide by 4:

x ≤ 5

Multi-Step Linear Inequalities

Multi-step inequalities require several operations. The same general principles used for solving linear equations can be applied, with special attention to multiplication or division by negative numbers.

Solve:

3x + 5 - x > 13

Combine like terms:

2x + 5 > 13

Subtract 5:

2x > 8

Divide by 2:

x > 4

Important Strategy

A useful order is to simplify both sides first, combine like terms, move variable terms to one side, move constants to the other side, and finally isolate the variable.

Variables on Both Sides

Sometimes a linear inequality contains the variable on both sides.

Consider:

5x - 2 > 2x + 7

Subtract 2x from both sides:

3x - 2 > 7

Add 2:

3x > 9

Divide by 3:

x > 3

The variable terms should be collected on one side before solving for the variable.

Linear Inequalities with Fractions

Fractions can be removed by multiplying every term by a common denominator. Remember that the direction of the inequality changes if the multiplier is negative.

Consider:

x/4 + 2 ≤ 5

Subtract 2:

x/4 ≤ 3

Multiply by 4:

x ≤ 12

Example with a Negative Fraction

Consider:

-x/3 > 2

Multiply both sides by -3. Since we multiply by a negative number, reverse the inequality:

x < -6

Linear Inequalities with Decimals

Decimal inequalities can be solved using the same operations used for whole numbers.

Solve:

2.5x + 1.5 ≤ 11.5

Subtract 1.5:

2.5x ≤ 10

Divide by 2.5:

x ≤ 4

Using Fractions Instead

In some problems, converting decimals into fractions can make the arithmetic easier. For example, 0.5 can be written as 1/2.

Linear Inequalities with Parentheses

When parentheses are present, use the distributive property before isolating the variable.

Solve:

2(x + 3) > 14

Distribute 2:

2x + 6 > 14

Subtract 6:

2x > 8

Divide by 2:

x > 4

Negative Distribution

Be especially careful when distributing a negative number.

For example:

-2(x - 3) < 10

Distribute -2:

-2x + 6 < 10

Multiplying or Dividing by a Negative Number

This is one of the most important rules in solving inequalities.

When multiplying or dividing both sides of an inequality by a negative number, reverse the direction of the inequality symbol.

Example

Solve:

-2x > 8

Divide both sides by -2. Because the divisor is negative, reverse > to <:

x < -4

Why Does the Sign Change?

Multiplying or dividing by a negative number reverses the order of numbers on the number line.

For example:

3 > 1

Multiplying both sides by -1 gives:

-3 < -1

The inequality must therefore be reversed to keep the statement true.

Compound Inequalities

A compound inequality combines two inequalities into one statement. It can describe a variable that must lie between two values or satisfy one of two conditions.

Between Two Values

Consider:

2 < x ≤ 7

This means x is greater than 2 and less than or equal to 7.

The possible values include 3, 4, 5, 6, and 7, as well as decimal values between the endpoints.

Solving a Compound Inequality

Consider:

2 < x + 1 ≤ 6

Subtract 1 from all three parts:

1 < x ≤ 5

Therefore, x must be greater than 1 and less than or equal to 5.

Checking a Solution

After solving an inequality, you can check a value from the solution set by substituting it into the original inequality.

Suppose the solution is:

x > 4

Test x = 6 in the original inequality:

2x + 1 > 8

Substitute 6:

2(6) + 1 > 8

13 > 8

The statement is true, so 6 belongs to the solution set.

Testing a Non-Solution

Test x = 3:

2(3) + 1 > 8

7 > 8

This is false, so 3 is not a solution.

Linear Inequality Word Problems

Linear inequalities are useful when a problem describes a maximum, minimum, limit, requirement, or range of possible values.

Example: Maximum Budget

Suppose you have ₱500 and want to buy items that cost ₱80 each. Let x represent the number of items you can buy.

Since you cannot spend more than ₱500:

80x ≤ 500

Divide by 80:

x ≤ 6.25

Since x represents a number of items, it must be a whole number. Therefore, the greatest possible number of items is 6.

Example: Minimum Requirement

Suppose a student needs at least 75 points to pass an examination. If the student currently has 60 points and can earn x additional points, then:

60 + x ≥ 75

Subtract 60:

x ≥ 15

The student needs at least 15 additional points.

Common Words in Inequality Problems

Words such as at least, at most, more than, less than, no more than, and no less than can help identify the appropriate inequality symbol.

Common Mistakes

Forgetting to Reverse the Inequality

The inequality must be reversed when multiplying or dividing by a negative number.

Incorrect:

-2x > 8 → x > -4

Correct:

-2x > 8 → x < -4

Using the Wrong Endpoint

An open endpoint is used for < and >, while a closed endpoint is used for ≤ and ≥.

Forgetting the Meaning of the Variable

In word problems, the variable may represent a whole number, such as the number of people, items, or days. Even if the algebra produces a decimal, the final answer may need to be interpreted according to the situation.

Not Checking the Original Inequality

Checking a value in the original inequality can help identify arithmetic or sign errors.

Summary

A linear inequality compares two expressions using symbols such as <, >, ≤, and ≥. Its solution is a set of values that makes the inequality true.

Important rules include:

1. Perform the same addition or subtraction on both sides.

2. Perform the same multiplication or division on both sides.

3. Reverse the inequality symbol when multiplying or dividing by a negative number.

4. Use an open endpoint for < or >.

5. Use a closed endpoint for ≤ or ≥.

6. Shade to the right for values greater than a number and to the left for values less than a number.

7. In word problems, carefully identify whether the situation describes a maximum, minimum, limit, or range.

Linear inequalities are an important part of algebra because they allow us to describe conditions and ranges of possible values rather than only one exact value.
